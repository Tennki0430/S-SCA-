## 記事構成

### 1. サムネイル画像（Gemini 3.1 Flash で生成）

noteの記事カバー画像。やわらかいイラスト調、パステルカラー。

### 2. 冒頭（引用ブロック）

予測シグナルを「」で一言提示。引用フォーマットを適用する。

```
「銅の価格が、14日後に+8%上昇する見通しです（AIによる参考予測値）」
```

### 3. 自己紹介（★必須 — 引用の直後に1段落）

```
S-SCA 市場分析ライターのソラです。世界の物流コスト・地政学リスクをAIで分析し、コモディティ価格の動向をわかりやすく伝えています。
```

### 4. リード文（2〜3段落、ソラの語り口で）

- 1段落目: 予測数字の提示 + 読者にとっての意味（なぜ今知るべきか）
- 2段落目: 商社経験を交えた共感
- 3段落目: この記事で何がわかるか（具体的アクション）

```
# 良い例（ソラの語り口）
AIが今朝算出した予測では、銅の価格が14日後に現在より約8%高くなる見通しです。

商社にいた頃、こういうシグナルが出た後に「あのとき動いておけばよかった」と言う人をたくさん見てきました。
大量に仕入れる必要はありません。次の発注分を少し前倒しにするだけでいい。

この記事では、なぜ今銅が上昇するのかと、あなたが取れる具体的なアクションをまとめます。
```

```
# NG例（AI感が強い）
銅価格の上昇が予測されており、仕入れのタイミングを検討することが可能です。
本記事では、銅価格の動向について網羅的に解説し、読者の一助となることを目指します。
```
