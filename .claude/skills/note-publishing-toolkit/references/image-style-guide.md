# 画像スタイルガイド（Gemini 3.1 Flash）— S-SCA 版

## APIモデル名

**`gemini-3.1-flash-image-preview`**（v1beta API）

他のモデル名は使わない。`gemini-2.5-flash` や `gemini-2.0-flash` は画像生成非対応。

## API呼び出し

```bash
source .env.local

PROMPT="ここにプロンプト"
OUTPUT="data/note-images/${SLUG}-thumb.png"

curl -s "https://generativelanguage.googleapis.com/v1beta/models/gemini-3.1-flash-image-preview:generateContent?key=${GEMINI_API_KEY}" \
  -H "Content-Type: application/json" \
  -d "$(jq -n --arg p "$PROMPT" '{
    contents: [{parts: [{text: $p}]}],
    generationConfig: {
      responseModalities: ["TEXT", "IMAGE"]
    }
  }')" \
  > /tmp/gemini-response.json

jq -r '.candidates[0].content.parts[] | select(.inlineData) | .inlineData.data' \
  /tmp/gemini-response.json | base64 -d > "$OUTPUT"
```

> `upload_file` は `$TMPDIR` か workspace 内のファイルしか受け付けない。`/tmp/` 直下は NG。
> `data/note-images/` 配下に保存して使うこと。

## 保存先

`data/note-images/{銘柄スラッグ}-{テーマ}-{種別}.png`

例: `copper-price-thumbnail.png`, `wheat-infographic.png`

## サムネイル画像のトンマナ（S-SCA 版）

### カラーパレット
- **メインカラー**: ネイビー（#1A2F5C）、ゴールド（#E8B84B）
- **サブカラー**: スカイブルー（#5DA5D4）、ライトグレー（#F4F5F7）
- **背景**: クリーンなグラデーションまたはシンプルな幾何学パターン
- **テキスト色**: ゴールドまたはホワイト（ネイビー背景上）

### スタイル
- **インフォグラフィック調**（写真風は避ける）
- シャープで信頼感のあるデザイン
- ビジネス・マネー系マガジンの表紙感覚
- 数字（予測変化率）を大きく目立たせる

### 構成要素
- テーマを象徴するアイコン（銅線・小麦・リチウム電池・グラフ等）
- **大きな数字テキスト**（「+8%」「14日後」等の予測値）
- **サブテキスト**（銘柄名・予測期間）

### サイズ
- **16:9の横長**（noteの推奨カバー画像サイズ: 1280x670px）

### 実績プロンプト（銅・価格上昇テーマ）

```
日本語のビジネスブログ記事のサムネイル画像を生成してください。横長（16:9）のアスペクト比で。
テーマは「銅の価格が14日後に+8%上昇予測」です。
ダークネイビー（#1A2F5C）を背景に、ゴールド（#E8B84B）のアクセントカラーを使い、
銅線や電材をモチーフにしたシンプルなアイコンと、大きな日本語テキスト「銅 +8% 上昇予測」を入れてください。
右下に小さく「14日後の参考予測値」と入れる。
インフォグラフィック調で、写真風にしないでください。
```

### テーマ別バリエーション

| テーマ | アイコン | 数字テキスト | サブテキスト |
|--------|---------|------------|------------|
| 銅 | 銅線・電材 | `+8% 上昇予測` | `14日後の参考予測値` |
| 小麦 | 小麦の穂・パン | `+6% 上昇予測` | `食品価格への影響` |
| リチウム | バッテリー・EV | `+12% 上昇予測` | `ポータブル電源・蓄電池` |
| VIX 急上昇 | 折れ線グラフ↑ | `VIX 急騰` | `市場の不安感が高まっています` |
| BDI 上昇 | 船・コンテナ | `BDI +15%` | `輸入品価格に注意` |

## 図解画像のトンマナ

### スタイル
- インフォグラフィック調
- サムネと同じカラーパレットで統一感を出す
- シンプルで情報量は絞る（3〜4項目まで）
- 日本語テキストは大きく、読みやすく

### 構成パターン

#### パターン1: 価格推移予測グラフ
現在価格 → 14日後予測価格を矢印で示す。

```
実績プロンプト例:
日本語のインフォグラフィック画像を生成してください。横長（16:9）のアスペクト比で。
銅の価格予測を示す図です。ダークネイビー背景、ゴールドのアクセント。
左に「現在」として基準価格（100）、右に「14日後」として+8%（108）を大きな数字で表示。
中央に上向きの太い矢印。下部に「AIによる参考予測値」と小さく注記。
シンプルで見やすいインフォグラフィック調。
```

#### パターン2: 物流コスト→価格連動フロー図
BDI上昇 → 輸送コスト増 → 仕入れ値上昇 → 消費者価格上昇 の流れを示す。

#### パターン3: 取るべきアクションチェックリスト
「今すぐやること」を3〜4項目の箇条書きで視覚化。

## 品質チェック（画像生成後に必ず確認）

1. **テキストの読みやすさ**: 日本語テキストが崩れていないか
2. **数字の正確性**: 予測変化率が記事と一致しているか
3. **カラーの統一感**: サムネと図解で同じパレットが使われているか
4. **アスペクト比**: 16:9の横長になっているか
5. **注記**: 「参考予測値」の文言が入っているか

問題があれば再生成する。プロンプトを調整して最初から生成し直す。
