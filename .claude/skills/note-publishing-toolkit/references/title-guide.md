# タイトル作成ガイド — S-SCA 価格予測記事

## 基本ルール

1. **メインKWはタイトルの左側（先頭〜15文字以内）に入れる**
2. **予測の数字（+○%など）を入れると具体性が増す**
3. **毎回パターンを変える** — テンプレ化しない
4. **32文字以内** — noteの一覧表示で切れないように

## テンプレ化NGの理由

以下のように毎回同じ構造だと、AIが書いた感がバレる:
```
❌ 銅の価格が上昇予測 — 仕入れのタイミングを解説【2026年5月最新】
❌ 小麦の価格が上昇予測 — 仕入れのタイミングを解説【2026年6月最新】
```

## 良いタイトル例（バリエーション）

### 銅テーマ
- 「銅が14日で+8%予測 — 電材を今すぐ発注すべき理由」
- 「銅線、今週中に買っておいて。値上がりのシグナルが出た」
- 「電材屋さんへ：銅の仕入れ、今が動きどきかもしれません」
- 「銅価格、14日後に動く？AIが出したシグナルを読む」

### 小麦テーマ
- 「小麦が値上がりする前に — 今すぐできる食品備蓄3つ」
- 「パスタ・パン、来月には高くなってるかも。今週買い足しておいて」
- 「小麦の先物が動き始めた。家庭でできる備蓄アクション」

### リチウムテーマ
- 「リチウム価格が上昇予測 — ポータブル電源、今が買いどき？」
- 「EV・蓄電池、値上がり前に買う？AIの予測を元に考える」
- 「リチウム高騰の前に — 今仕込んでおきたい電池製品リスト」

### VIX / マクロテーマ
- 「VIXが急上昇したとき、なにが起きる？初心者向け解説」
- 「恐怖指数が上がってる。今は動く時期か、待つ時期か」
- 「BDIが教えてくれること — 輸入品の値上がりを先読みする方法」

## パターン分類

| パターン | 構造 | 例 |
|---------|------|-----|
| 数字型 | 「{KW}が{日数}で+{%}予測 — {アクション}」 | 銅が14日で+8%予測 — 電材を今すぐ発注すべき理由 |
| 命令型 | 「{KW}、{タイミング}に{アクション}して」 | 銅線、今週中に買っておいて。値上がりのシグナルが出た |
| 疑問型 | 「{KW}、{タイミング}に動く？AIの予測を読む」 | 銅価格、14日後に動く？AIが出したシグナルを読む |
| 値上がり前型 | 「{KW}が値上がりする前に — {アクション}」 | 小麦が値上がりする前に — 今すぐできる食品備蓄3つ |
| 対象者型 | 「{読者}へ: {状況}、{アクション}かもしれません」 | 電材屋さんへ：銅の仕入れ、今が動きどきかもしれません |

**同じパターンを連続で使わない。** 最低3パターンはローテーションすること。

## サブKWの見出しへの配置

メインKWはタイトルに入れるが、サブKWは見出し（h2）や本文に自然に散りばめる。

例（メインKW: 銅 仕入れ）:
- h2: 「なぜ今銅は上昇するのか」← 「銅 上昇 理由」がサブKW
- 本文: 「電線・電材の価格に直結します」← 「電材 価格」がサブKW
- h2: 「まとめ：銅の仕入れ、今週中がベスト」← 「銅 仕入れ 今週」がサブKW
