# S-SCA 作業レポート｜2026年5月1日〜4日

## 5月2日（土）

**アフィリエイト機能の初期実装**

- `affiliate_writer.py` を新規作成。Oracle の予測が閾値（±5%）を超えた銘柄について、自動でアフィリエイト記事を生成・投稿するエージェントを追加
- X と note への同時投稿フローを構築
- GitHub Actions に関連 Secrets（NOTE / X / Amazon）を追加
- Supabase の無料枠維持のため、90日超の古い `market_data` レコードを毎時自動削除する仕組みを追加
- `AFFILIATE_THRESHOLD_PCT` が空文字列のとき `ValueError` になるバグを修正

## 5月3日（日）

**note 投稿・Amazon アフィリエイトの実装改善**

- note 投稿をメール/パスワード認証から Playwright 自動化に移行
- note のセレクタが実際の DOM に合わず投稿できない問題を修正
- Amazon アフィリエイト URL の管理方法を段階的に改善:
  - `amazon_links.yaml` 手動管理 → PA API（方法B）→ Claude Haiku 提案 + ASIN スクレイピング（方法A）に決定
- アイキャッチ画像のアップロードフローを修正・安定化
- note の OGP カードリンク方式に移行（URL を本文に貼るだけで商品カードが表示）
- Discord への画像添付を削除しシンプル化

## 5月4日（月）

**Prophet/CmdStan 障害の根本解決 + プロジェクト整理**

- Prophet の `stan_backend` エラーにより全銘柄の予測が停止していた問題を解決
  - 原因: pip wheel に含まれる `cmdstan-2.33.1` ディレクトリが不完全（Makefile なし）
  - 対策: CmdStan 2.33.1 を Prophet パッケージ内ディレクトリに直接インストール＋キャッシュ
  - 結果: 全5銘柄（Wheat/Corn/Naphtha/Copper/Lithium）の予測が正常稼働
- note セッションを GitHub Secret 経由で CI 環境に復元する仕組みを整備
- プロジェクト整理:
  - 不要な環境変数 8 つを削除（NOTE_EMAIL/PASSWORD、GEMINI_API_KEY、PA API キー等）
  - 旧 cookie 方式の投稿コード（`_post_note`, `_upload_note_image`）を削除
  - `src/utils/amazon_paapi.py` を削除
  - 開発用スクリプト 8 本を `scripts/dev/` に移動
- X API: キー再生成・権限変更を実施。無料プランでは投稿不可（402）と判明。エラーはパイプラインに影響しないことを確認
